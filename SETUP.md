# Deployment guide

1. Open https://github.com/AmanNishad-ic/AmanNishad-ic (the profile repository). If absent, create a public repository named exactly `AmanNishad-ic` under the `AmanNishad-ic` account.
2. Back up the existing README and workflows. Clone the existing repository, copy the **contents** of the extracted folder into the clone, including hidden `.github`, and review the diff. Remove conflicting older profile-generation workflows if appropriate.
3. Commit and push to the repository's default branch. Example commands from the clone:

```bash
git add README.md assets scripts .github/workflows requirements.txt SETUP.md
git commit -m "Launch animated AI engineering profile"
git push
```

4. In Settings → Actions → General, enable actions and allow the workflow token to write repository contents. Branch rules must permit the bot's commits. Workflows explicitly request `contents: write`.
5. In Actions, manually run `update-stats`, `profile-3d`, and `Contribution snake`, one at a time on the default branch. Check each run and inspect the generated SVG in `assets/`. All three workflows commit to the default branch, not a separate output branch; README paths match. Scheduled runs follow daily at staggered UTC times. A shared concurrency group reduces conflicting pushes; GitHub may replace pending runs, so manual runs should be sequential.
6. Visit the public profile in light and dark mode. GitHub may disable or cache some SVG animation. All hand-authored panels retain static content. Snake is generated by Platane/snk/svg-only@v3 and its contribution grid uses dark colors; surrounding transparency may follow the visitor theme.

## Statistics

The first-run panels explicitly show that data has not yet been fetched. The Python generator uses GitHub GraphQL, paginates public owned repositories, sums their stars and language bytes, and uses the returned contribution calendar. Longest streak refers to that calendar window, not lifetime. Contribution visibility follows GitHub API/account permissions. The isometric graph is a local generator, avoiding a third-party 3D action. No external Python packages are required. To generate locally, set `GITHUB_TOKEN` in your environment using a suitably scoped token, then run `python scripts/generate_stats.py --mode stats` and `python scripts/generate_stats.py --mode 3d`. Do not commit credentials. API errors fail the run without replacing existing assets. No workflow execution was performed in the delivery environment.
